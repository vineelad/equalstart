EQUAL START PHASE 2: RESULTS AND DESIGN NOTES

Implemented
- Bounded Discovery actions: search, fetch an approved source, ask one optional
  clarification, or finish. Missing personal information stays unknown.
- At most two searches and three fetch attempts per matching run. Initial
  research uses up to two source fetches; one evidence-driven follow-up can use
  the remaining slot for a different reviewed URL. No unreviewed lead is promoted.
- Official source snapshots with URL, retrieval time, and stable source ID.
  Six-hour receipts can be reused. The reviewed catalog is not silently changed.
- Evidence judges Supported, Contradicted or Not found claims. It selects a
  numbered passage; code copies exact text. Source/opportunity IDs, coverage,
  duplicate references and passage indices are validated. Localization does not
  establish semantic support or complete eligibility.
- Evidence uncertainty flows into Fit and student-facing readiness. The default
  shows up to three selected recommendations; the broader catalog is separate.
  Empty Discovery output stays an empty recommendation set.
- Side-by-side funding/housing/travel comparison, known-versus-unknown checks,
  conservative suggested prerequisites/dates, and editable support drafts.
  Suggested dates are not provider deadlines. Students review and send drafts.
- Sanitized trace export and persistent source receipts; profiles stay in session.
- Model costs attributed to usage-row IDs. Concurrent reservation settlements
  cannot create negative per-case costs. Ambiguous calls retain reservations.

Learning demonstrated
Tool selection, conditional routing, bounded autonomy, stopping criteria,
grounding with deterministic citation localization, uncertainty, agent handoffs,
planning, human review, privacy-conscious state, evaluation and ablation.
The same four specialist roles remain; tool control is deterministic code.

Interpretation and limits
Cases and labels are AI-assisted development artifacts, not independently
reviewed annotations, held-out generalization estimates or real student trials.
Prompts were revised after inspecting failures. There is no significance claim.
Journey sources are controlled fixtures, not live retrieval benchmarks. The
real-provider UI check demonstrates integration, not factual accuracy. Journey
timings include an environment interruption and are not a speed benchmark.
Costs include retained reservations for uncertain billing; external account
billing is not independently audited. Historical concurrent shared-ledger cost
deltas have COST_NOTE.txt annotations; use the final request-ID-attributed runs.

Future work
Full durable graph checkpoint/resume with a privacy design for profile storage;
independently reviewed real-task labels, student usability and coverage/fairness
assessment; authentication and per-user isolation before shared personal use.
Source caching is completed retrieval reuse, not full graph recovery.
