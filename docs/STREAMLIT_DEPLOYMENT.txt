Equal Start: Streamlit Community Cloud

Deployment state: source prepared; deployment requires the owner's Streamlit login.
Do not describe the app as hosted until Streamlit returns a working app URL.

Create the app at https://share.streamlit.io/ using:
  Repository: vineelad/equalstart
  Branch: deploy/streamlit-community-cloud
  Main file: streamlit_app.py
  Advanced settings / Python: 3.12
  Custom subdomain: equalstart-demo (only if available)

This branch includes Phase 2; it can be deployed before PR #2 merges.
The public entrypoint keeps saved plans and checklist progress in each browser
session, while sharing server-side source receipts and an inference usage ledger.
Lost sessions and host restarts lose plans. Students should download checklists.
The local app.py entrypoint still uses persistent single-user saved plans.

Initially deploy without secrets to check the UI in local matching mode. For live
agents, add ROOT-LEVEL secrets in Streamlit Advanced settings (not a [section]):

LLM_PROVIDER = "nebius"
NEBIUS_API_KEY = "paste the existing Nebius key privately here"
NEBIUS_MODEL = "zai-org/GLM-5.3-Flash"
NEBIUS_INPUT_PER_MILLION = "0.15"
NEBIUS_OUTPUT_PER_MILLION = "0.50"
INFERENCE_BUDGET_USD = "2"
KEENABLE_API_KEY = "paste the existing key privately here"

The $2 value is a suggested hosted-demo allocation, not a newly authorized budget.
It is part of the existing cumulative $15 inference allowance, not additional.
Do not post actual secrets in GitHub, chat, logs, screenshots or documentation.
Root-level Streamlit secrets are loaded before model configuration, becoming env
variables. No local .env file is uploaded. Without keys local matching still works.

The hosted entrypoint defaults to Nebius; an explicit LLM_PROVIDER secret overrides
it. All four agent roles use the same selected inference provider. Keenable still
handles discovery searches and source retrieval. There is no automatic failover
to Fireworks. Missing Nebius credentials/rates leave deterministic local mode.
The GLM-5.3-Flash rates above were verified against Nebius's public model catalog
on 2026-11-05; recheck if the model or pricing changes:
https://tokenfactory.nebius.com/api/public/models_info
Token Factory credits fund inference; free Streamlit hosting needs none.
Optional Fireworks: set LLM_PROVIDER to fireworks and provide FIREWORKS_API_KEY
and FIREWORKS_MODEL. That provider uses its own account, not Nebius credits.

Nebius validation: phase2-20261106T041109951596Z evaluated the current Phase 2
contracts using GLM-5.3-Flash. Each role passed 5/5 cases with 100% contract validity
in one repeat (19 API calls plus one empty Planning guard). This is a small synthetic
development check, not repeated-run stability or real-student validation. See its
report under docs/evals/ for outputs and limitations. Test cost: $0.00136185.

Public visitors do not see the runtime budget display, cross-session stage logs,
provider keys or full evaluation-result download. Agent scorecards stay visible.
Historical evaluation reports are already public in the source repository; those
development costs are not account balances or current runtime usage.

Budget limitation: Community Cloud disk and SQLite are ephemeral. The local
authoritative ledger is not uploaded. Host rebuilds can reset the hosted ledger;
an app-only cap cannot guarantee cumulative billing across those resets. Configure
provider-side spending controls where supported and reconcile hosted spend with
the local ledger before further paid development. Keenable has separate usage;
the inference cap does not limit search charges. Do not assume zero balance stops
all billing automatically. No new paid resources are created by these instructions.

This is a session-based capstone demo, without durable accounts or authentication.
